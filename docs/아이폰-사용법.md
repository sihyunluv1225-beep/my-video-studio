# 아이폰에서 NOW BARRE VIDEO STUDIO 쓰는 방법

## 1. 앱 열기

1. 아이폰 **Safari** 로 앱 주소에 들어갑니다. (주소는 GitHub Pages 를 켠 뒤 생겨요. 아래 「앱 주소 만들기」 참고)
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** 를 누르면, 홈 화면에 NOW BARRE 아이콘이 생겨서 일반 앱처럼 열 수 있어요.

> 크롬이나 인스타그램 안의 브라우저 말고 **Safari** 를 써 주세요. MP4 저장이 가장 안정적이에요.

## 2. 영상 만들기 순서

| 순서 | 탭 | 할 일 |
| --- | --- | --- |
| 1 | 홈 | A CLASS REELS / B MASTER EDUCATION / C BRAND PROMOTION 중 하나 선택 |
| 2 | 위쪽 | 15초 · 20초 · 30초 · 60초 중 길이 선택 |
| 3 | 영상 | 「앨범에서 영상 추가」 → 여러 개 선택. 자동으로 길이에 맞게 나눠져요 |
| 4 | 영상 | ↑↓ 로 순서 바꾸기, 「구간 자르기」로 쓰고 싶은 부분만 남기기 |
| 5 | AI | 「자동 편집」 한 번 누르면 좋은 장면 고르기 + 박자 맞추기 + 색감까지 |
| 6 | 자막 | 재생 위치를 옮기고 「지금 위치에 자막 추가」 |
| 7 | 브랜드 | 로고(PNG) 넣기, 슬로건·교육 안내 문구 입력 (한 번 넣으면 기억돼요) |
| 8 | 음악 | 「파일」 앱의 mp3/m4a 음악 넣기, 소리 크기와 BPM 조절 |
| 9 | 저장 | 「영상 만들기」 → 끝나면 「사진 앱에 저장하기」 → **비디오 저장** |

## 3. 저장할 때 주의할 점

- 영상 길이만큼 시간이 걸려요. (30초 영상 = 약 30초)
- 만드는 동안 **화면을 끄거나 다른 앱으로 가지 마세요.** 멈출 수 있어요.
- 무음 모드(옆 스위치)여도 영상 소리는 녹음돼요. 미리보기 소리가 안 들리면 무음 모드를 꺼 보세요.
- 오래된 아이폰에서 끊기면 「가볍게 720×1280」 화질로 만들어 보세요.

## 4. 앱 주소 만들기 (처음 한 번만)

이 앱은 무료 호스팅인 **GitHub Pages** 로 인터넷 주소를 만들 수 있어요.

**중요:** 지금 저장소(my-video-studio)는 **비공개**예요. GitHub 무료 요금제에서는 **공개 저장소에서만** Pages 를 쓸 수 있어요.
공개로 바꾸면 **프로그램 코드**가 공개돼요. 대표님의 **영상은 어디에도 올라가지 않으니** 영상이 공개되지는 않아요.
(참고: `docs/profile.md` 의 소개글도 함께 공개돼요. 원하지 않으면 공개 전에 말씀해 주세요. 지워 드릴게요.)

공개로 바꾸기로 하셨다면:

1. GitHub 에서 이 코드가 `main` 에 합쳐져 있어야 해요. (Pull Request 를 만들어 Merge)
2. 저장소 **Settings → General → 맨 아래 Danger Zone → Change visibility → Public**
3. **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택
4. **Actions** 탭에서 「Deploy to GitHub Pages」를 실행하거나, `main` 에 새로 반영되면 자동으로 올라가요.
5. 몇 분 뒤 `https://sihyunluv1225-beep.github.io/my-video-studio/` 주소가 생겨요.

이 과정에서 비용은 들지 않아요.
