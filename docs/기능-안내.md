# 기능 안내

## 지금 바로 쓸 수 있는 기능

| 구분 | 기능 |
| --- | --- |
| 기본 편집 | 앨범에서 여러 영상 불러오기, 9:16 세로 화면 자동 맞춤, 15/20/30/60초 선택 |

| 브랜드 | 로고 이미지 넣기(위치 선택), 브랜드 이름·한글 이름·슬로건, 오프닝 타이틀, 엔딩 화면 |
| 브랜드 | 교육 일정 안내 엔딩 카드 (MASTER EDUCATION) |
| 음악 | 배경 음악, 원본 소리·음악 소리 크기 조절, 음악 시작 지점 |
| 음악 | BPM 설정(125·128·130 빠른 선택), 톡톡 두드려 BPM 재기, 2/4/8박마다 컷 |
| 효과 | 색감 5가지(원본·웜 베이지·필름·흑백·화사하게), 전환 4가지(컷·플래시·페이드·줌) |
| 저장 | MP4 저장(아이폰 Safari), 1080×1920 또는 720×1280, 사진 앱에 바로 저장 |

## AI 자동 편집

모든 AI 기능은 **아이폰 안에서** 동작해요. 영상을 외부로 보내지 않고, 비용이 들지 않아요.

| 기능 | 상태 | 방법 |
| --- | --- | --- |
| 주요 장면 추천 | 사용 가능 | 영상의 움직임을 분석. CLASS 는 역동적인 장면, EDUCATION 은 차분하고 자세가 잘 보이는 장면 |
| 불필요한 구간 제거 | 사용 가능 | 앞뒤의 멈춰 있는 부분(카메라 세팅·대기)을 잘라냄 |
| 음악 박자 맞춤 컷 | 사용 가능 | BPM 에 맞춰 컷 길이를 박자 단위로 나눔 |
| 분위기 효과 추천 | 사용 가능 | 스타일과 영상 밝기에 맞는 색감·전환 추천 (규칙 기반) |
| 한국어 음성 자동 자막 | 준비 중 | 무료 오픈소스 Whisper 를 아이폰 안에서 실행할 계획 |
| 자연스러운 화면 전환 | 준비 중 | 장면 움직임 방향에 맞춘 전환 자동 선택 |
| 음악 BPM 자동 인식 | 준비 중 | 음악 파형을 분석해 BPM 자동 측정 |

새 AI 기능은 `src/ai/registry.js` 목록에 추가하는 구조로 만들어 두었어요.
외부 서비스(유료 API 등)가 필요한 기능은 **대표님 승인 없이 연결하지 않아요.**

## 알아 두실 점

- 저장은 화면을 그대로 녹화하는 방식이라 영상 길이만큼 시간이 걸려요.
- 편집 중인 영상 목록은 앱을 닫으면 사라져요. (영상 파일을 기기에 따로 저장하지 않는 개인정보 보호 설계)
- Apple Music 스트리밍 곡은 불러올 수 없어요. 「파일」 앱에 있는 음원 파일을 사용해 주세요.
